# 巨手：表达检测与复核

初稿和每次实质修改后，先读取 [Humanizer-zh](../skills/humanizer-zh/SKILL.md)，通读全文，处理空话、重复和妨碍理解的句式。再对照来源和改写前文本，确认数字、限定条件、原话和作者声音没有丢失。审稿不能编造经历或削弱有作用的情绪。

完成语义审阅后，运行 `python3 <完整检查器路径> --wechat-export <正文路径>`，再执行 `pnpm check-prose -- <正文路径>`。检查器安装路径见 [运行准备](运行准备.md)。仓库检查会输出未审模板或具体错误；按真实段落完成复核后重跑。

硬命中必须修复后重跑。人工提醒逐项阅读，根据所在段落给出保留或修改的理由；修改后重新检查。使用仓库提供的复核流程，把实际提醒、正文哈希与检查器哈希绑定。不得手写空提醒集合、伪造 reviewed 标记或复用旧版本证据。

表达检查的零命中不代表事实核验通过。来源密度、图片、链接、小程序、移动排版以及官方草稿回读仍须各自通过。检查器缺失或检查结果无法解析时，先解决依赖，保持上传阻断。
