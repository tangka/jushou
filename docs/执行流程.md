# 巨手：从素材到草稿与发表

先确认本次账号、任务范围和已有授权，再检查对应登录状态。
复用完整素材，核对真实已发表记录，避免重复采集、重复成稿和重复入箱。

只检查公众号时执行 `pnpm login-check -- --no-channels`；需要同步时在登录通过后运行对应账号命令。多账号以私有配置的 envAccount 选择器隔离，不能从显示名称猜选择器。所有文章同时出现零阅读或解析失败时先区分限流与登录失效，不贸然重置登录。

写稿前读取账号定位和选题策略，生成版本2编辑任务；正文和来源审计一起完成。
Humanizer-zh审稿、表达检查、来源密度、图片和排版检查通过后，执行本机dry-run。
本机通过后使用本号配置调用remote-upload-draft.sh，并保留幂等记录。
从官方草稿箱回读实际账号、标题、正文、摘要、封面、图片、链接与版本。

上传入口为 `pnpm upload-draft -- --dry-run --draft <本篇目录>`；通过后执行 `scripts/remote-upload-draft.sh --env <本号env文件> --draft <本篇目录>`。环境、白名单机器和目录均使用自己的配置。结果未知先查询既有记录和官方草稿，不重复新建；官方回读之后按实际观测运行 `verify-daily-drafts`，不把上传回执替代官方回读。

草稿任务在官方回读通过后结束。
明确授权发表时，由Agent加载已安装的wechat-publication和ego-browser技能，操作本号微信后台。
Ego登录状态需要单独核对；发表过程以实际后台身份和精确稿件版本为准。
官方显示已提交或审核中时记录真实状态；只有已发表证据才能写已发表。

当前看板提供账号和数据视图，没有公众号发表按钮。`publish-html`只生成HTML，`channels:publish-today`属于视频号，`verify-daily-publications`只核验记录；公众号发表由Agent依照发表技能调用Ego完成。
