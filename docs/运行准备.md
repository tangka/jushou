# 巨手：运行准备

这些文件让 Agent 知道怎样执行任务。Hono 服务和 React 看板可以独立启动；写稿、图片生成和 Ego 发表还需要各自的工具与登录。Markdown 不会自动安装这些外部能力。

## 配置并启动

在仓库根目录执行：

```bash
corepack pnpm install --frozen-lockfile
corepack pnpm build
cp -n operator.example.json operator.local.json
```

把 `operator.local.json` 中的占位路径、账号名称和账号 ID 改成自己的值。`env.OBSIDIAN_VAULT` 必须是自己的本地资料目录；账号名与 `WECHAT_ACCOUNT_EXACT` 对应微信后台实际名称。账号凭据只写入本机配置或相应 `.env`，不要写进 MD、提交或日志。远端草稿上传需要填写自己的 `remoteUpload` 和相应账号凭据。

```bash
corepack pnpm operator:check
corepack pnpm --dir web install --frozen-lockfile
corepack pnpm --dir web build
corepack pnpm start
```

服务默认使用 3333 端口。登录入口为 `http://localhost:3333/`，账号页为 `/?account=<账号ID>`，看板为 `/dashboard/?account=<账号ID>`。按本号身份扫码；不要假定另一个号的登录可共用。

## 准备账号工作目录

默认账号根目录为 `<OBSIDIAN_VAULT>/微信公众号/<账号精确名称>/`；配置 `WECHAT_ACCOUNT_ROOT` 时使用其实际值。

1. 将 [账号定位模板](../examples/account/账号定位.md) 复制为本号根目录的 `账号定位.md`，改成自己的读者、选题和表达要求。
2. 将 [账号目录入口](../examples/account/AGENTS.md) 复制为本号根目录的 `AGENTS.md`，替换其中的仓库绝对路径占位符。它需要引导 SDK 会话回到本仓库读取规则。
3. 账号目录下保存自己的 `素材/`、`已发布/`、`待发布/`、`数据/` 和 `主题/`。不要把这些运营内容提交到公开仓库。
4. 按 [任务示例](../examples/tasks/每日任务.md) 填写本次主题和真实来源路径。不要直接运行仍有占位符的任务，也不要把正文模板当作可上传的成稿。

`pnpm draft` 启动的 SDK 写稿会话以账号根目录为工作目录，不能假定它会继承仓库根目录的 `AGENTS.md`。主 Agent 可以直接读取仓库内规则；SDK 会话需要账号入口或任务中的明确路径。

## 技能与外部能力

| 能力 | 仓库提供 | 使用者准备 |
| --- | --- | --- |
| 通用写作规则 | `skills/wechat-human-writing/SKILL.md` 与 `references/author-voice.md` | 模型或 Agent 登录、本号作者偏好、真实素材 |
| 中文审稿 | `skills/humanizer-zh/SKILL.md` 与其 MIT 许可证 | Agent 逐段执行审阅 |
| 程序表达门禁 | 仓库的 `pnpm check-prose` 和上传校验入口 | Python 3、完整 `wechat-human-writing` 的 `scripts/check_prose.py` |
| 公众号发表 | `skills/wechat-publication/SKILL.md` | Ego 运行时、当前版本 `ego-browser` 技能、本号登录与实际授权 |
| 素材和图片 | 本地路径与校验协议 | 按需要安装采集、截图和封面工具；已有完整素材直接复用 |

本次公开的写作技能目录只包含通用 MD，**不包含 `scripts/check_prose.py`**。程序会先读取 `WECHAT_HUMAN_WRITING_CHECKER` 指定的完整检查器，再找 `~/.agents/skills/wechat-human-writing/scripts/check_prose.py` 和 `~/.codex/skills/wechat-human-writing/scripts/check_prose.py`。必须安装完整检查器并执行其自检；缺失时上传会拒绝继续。不能用只返回成功的占位脚本替代。

```bash
# 改为已经安装的完整检查器路径；本机与远端上传使用同一份文件
export WECHAT_HUMAN_WRITING_CHECKER=/absolute/path/to/wechat-human-writing/scripts/check_prose.py
```

Agent 的技能发现目录由所用客户端决定。可以在任务中显式指向仓库内 SKILL.md；需要安装时，把整个相应技能目录放入客户端支持的位置。若已有完整技能，保留其脚本、许可证和私有偏好，先比较差异，不能用只有 MD 的目录覆盖完整安装。

## 最小验证

首次启动先验证 `operator:check` 和本号登录，再用真实素材完成一篇本地稿。表达、来源、图片和 dry-run 都通过后才能入箱。远端白名单配置、Ego 登录或发表授权未准备好时，只交付已实际完成的阶段；不要把启动成功写成已入箱或已发表。
