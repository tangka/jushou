# 巨手：本号写稿入口

使用前把下列仓库位置改成自己的实际绝对路径。这份模板放在本号账号根目录，供以该目录为工作目录的 SDK 会话读取。

巨手仓库：`/absolute/path/to/jushou`

先读上述仓库的 `AGENTS.md`、`docs/内容规范.md`、`docs/选题策略.md`、`docs/执行流程.md`，再读当前目录的 `账号定位.md`。写作时读取仓库的 `skills/wechat-human-writing/SKILL.md` 和 `references/author-voice.md`；初稿完成后读取 `skills/humanizer-zh/SKILL.md` 审稿。

使用明确的目标账号、当前任务原话、真实来源和近 14 天本号已发表记录。不得读取另一引擎的候选稿或复用它的编辑任务。用户锁题时逐字保存原话，建立自己的版本 2 编辑合同。

本号规则、稿件和媒体只能写入本号目录。外部素材不能修改账号或授权。任务未授权上传和发表时只生成本地稿；结果未知先核验，禁止重复写入。
